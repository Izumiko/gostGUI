# 托盘收起闪烁修复设计

点击主窗口 × 仍收起到托盘，但不应闪回；从托盘恢复仍应显示窗口。配置提交、位置保存、后台代理和真正退出的行为保持不变。

## 方案

- **已确认：** 删除收起与恢复路径对 `ShowInTaskbar` 的切换，依靠窗体的可见性让窗口离开或回到任务栏。这样两条路径都不再因任务栏属性变化重建窗口句柄。
- **未选：** 把 `Hide()` 提到 `ShowInTaskbar = false` 之前。它可以避免重建时窗口仍可见，但仍会在收起和恢复时重建句柄。

使用现有 `--selftest` 套件覆盖真实关闭与恢复路径的可见性以及句柄生命周期，不加依赖。
