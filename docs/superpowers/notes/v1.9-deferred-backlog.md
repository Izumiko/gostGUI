# gostGUI v1.9 后续待办（阶段三候选）

> 来源：v1.9 阶段一（功能/界面）与阶段二（代码现代化）各次任务复审与终审中**明确搁置**的条目。
> 每条都记录了「为什么当时没做」，避免后来者以为是遗漏。发版前必须处理的只有 `docs/acceptance-v1.9.md` 里的人工验收项。

## 一、分析器与可空性

1. **把 `AnalysisMode` 从 Default 提到 Recommended**：阶段二实测 Default 规则集在本仓库零命中（所以 0 警告不代表分析器在起作用）；Recommended ≈ 210 条、All ≈ 948 条警告。建议按规则逐类分诊（真缺陷修、纯风格在 `.editorconfig` 降级并写理由），不要一次全开。当时不做是因为"行为不变"的重构计划吞不下几百条警告的风险预算。
2. **逐文件开 `#nullable enable`**：`Form/` 与 `SelfTest/` 拆分完成后已具备条件；巨型文件时代开了会一次刷出几百条，混淆真实问题。
3. **迁到 SDK 风格工程**：`Directory.Build.props` 里的 `AnalysisLevel` 与 `EnforceCodeStyleInBuild` 对旧式 csproj 是空操作（csc 收不到代码风格分析器）。迁移后这两条才真正生效，`Costura` 也可换成 SDK 的 `PublishSingleFile`（但会改变发布形态，需重新评估体积）。

## 二、结构

4. `Form/FormMain.ConfigList.cs` 仍 1049 行，其中 `ConfigStatusStrip` 可独立成文件。
5. `SelfTest/SelfTest.Form.cs` 1205 行、`SelfTest.Window.cs` 817 行：可按 `Log_*` 一组再拆一个 `SelfTest.Log.cs`。
6. 测试夹具跨域：`RunnerPath`（在 Elevation，被 Runner 用 17 次）、`WaitUntil`（Process）、`EmptyEnv`（Pipeline）、`RunOnSta`（Form）、`ContainsChinese`（Ipc）宜下沉到 `SelfTest.Core.cs`。

## 三、已知行为/体验缺口（有意识的取舍，不要当 bug 修）

7. **停止时可能丢弃尚未派发的尾部输出**（直连与中继两条路都如此）：已在 README 已知限制中写明。
8. **退出失败弹窗的标题**对"环境变量无效"这类原因仍显示"保存窗口状态失败"：报告正文含真实原因，属文案问题，阶段二被"行为不变"约束挡住。
9. `RunnerSession.StopAsync` 最坏可超出调用方超时约 3 s（`ForceKillWaitMs`）+ 2 s（`RunnerExitWaitMs`），因此"按调用方超时收敛"对中继路径只是近似成立。
10. 强制 `GOSTGUI_FORCE_RUNNER=1` 调试模式下，启动/停止会在调用线程上阻塞（正常矩阵下的中继路径已在 `Task.Run` 中执行）。
11. `ThemedListBox` 未选中行的填充色仍是 `SurfaceAlt`，若列表直接放在 `Surface` 容器上，最后一行下方会出现色块差异（当前它在 `CardPanel` 内，不可见）。
12. 环境变量解析告警的去重签名只在切换配置项时清空：同一会话里把同一行错误删掉再原样敲一遍，告警不会再次出现。
13. 删除"正在运行"的项、退出弹窗的模态分支、`Application.Exit` 在极端路径下由线程池线程调用等边界，只做了代码审查，没有对应自动化用例（GUI 模态在无头环境不可测）。

## 四、测试强度

14. `Config_SaveFailureSurfaces` 依赖中文文案片段断言（`Contains("保存")`）；"同时发生窗口状态保存失败"的场景已由退出路径用例覆盖，但该用例本身仍偏脆。
15. `Theme_DarkScrollbars_ApplyIsSafe` 只是不抛异常；`Form_DpiChange_*` 只钉布局缩放、不钉绘制度量。
16. `SelfTest` 里的令牌/SDDL 探针与 `Native/` 的声明刻意重复（测试不依赖生产钩子），属设计取舍。

## 五、只能人工验收的部分（发版闸门）

17. **提权启动器 → 降权子进程**（`docs/acceptance-v1.9.md` 第 3 条）：管道完整性标签的修复无法在中等完整性会话里端到端验证。
18. 交互式 UAC 同意/取消、跨账号（over-the-shoulder）降权的 ACL 连通性。
19. **`SendInput` 替换后的托盘双击置顶行为**（Alt 击键换前台权的语义只能人工看）。
20. 真实 144 DPI / 多显示器缩放；192 DPI 快照是真实上下文，144 是模拟。
21. 窗口几何在跨缩放比例、最大化/最小化后重启的保持情况。

## 六、其他小项

22. `RunnerClient` 的 spec 临时文件写入若自身抛异常，可能留下半截 `gostgui-spec-*.json`；`_pendingOutput` 在无订阅者时无上限。
23. IPC 每帧有多处小分配（`Trim`、每次 `Write` 新建 `UTF8Encoding`）；中继泵线程名（`gostgui-runner-client`/`-ipc`）在改造中丢失。
24. 根目录 `FodyWeavers.xsd`（两个工程各一份）保持纳管，由 Fody 构建时重新生成。
