# gostGUI v1.9 人工验收清单

> 适用版本：`gostGUI v1.9`（两个 exe 版本均为 `1.9.0.0`，产品版本 `1.9`）
> 前置：已用 **Rebuild** 产出 `gostGUI\bin\Release`（两个 exe + 两个 `.exe.config` + `config.json`，无散落第三方 dll）。
> 自动化已覆盖：构建、`--selftest`（130 个用例）、`--runner-smoke`、离屏快照（96/150/200%）。以下两类原“人工检查项”已完全自动化，不再列入下面的清单：
> - **升级兼容**（旧 v1.8 配置只留 `name/enable/program/args`）：`Load_OldFormat_GetsDefaults`、`Save_ThenLoad_RoundTripsNewFields`。
> - **路径解析**（裸命令 / PATH / PATHEXT / 引号 / 相对路径 / `%VAR%` 与实时解析提示）：`Resolve_*`、`Pipeline_*`、`Form_ResolvesProgramHint`、`Form_EnvPathEditRefreshesHint`。
> 本文件只列**必须真人操作**的条目；每条都写死了预期结果，请逐条记录“通过 / 失败（现象）”。
> 失败时请附上该配置项的日志原文（每项日志独立，可直接复制）。

## 准备

1. 准备一个会持续输出、可被正常结束的控制台程序作为“普通项”（例如 `cmd /c ping -n 600 127.0.0.1`）。
2. 准备一个 `requestedExecutionLevel=requireAdministrator` 的程序作为“管理员项”（例如系统自带的 `msconfig.exe`，或带管理员清单的测试程序）。
3. 按被测场景分别以**标准权限**和**管理员权限**启动 `gostGUI.exe`（管理员启动请右键 →“以管理员身份运行”）。
4. 每轮开始前把 `config.json` 备份一份，结束时恢复。
5. 发布门禁要求先用干净 `Rebuild` 产出完整文件集：`gostGUI.exe`、`gostGUI.Runner.exe`、`config.json` 三个文件 + 两个 `.exe.config`，且 **0 个散落 dll**；增量构建的残留不算数。

## 清单

| # | 场景与操作 | 预期结果（逐字核对） | 结果 |
|---|---|---|---|
| 1 | **标准权限**启动 gostGUI。给“管理员项”勾选“以管理员身份运行”，点该项的“启动”。 | 恰好弹出 **1 次** UAC；同意后该项日志出现启动信息，目标程序的 stdout/stderr **实时**滚动；点“停止”后进程消失、日志出现停止/退出记录；工具不卡死。 | ☐ |
| 2 | 同上，但在 UAC 弹窗点“否”。 | 该项日志恰好出现一行 `已取消管理员授权`；**没有**任何子进程被启动；gostGUI 不崩溃、不退出；按钮恢复可用。 | ☐ |
| 3 | **以管理员身份**启动 gostGUI。启动一个**没有**勾选“以管理员身份运行”的普通项。 | 任务管理器中该子进程的“权限/虚拟化”列显示为 **标准**（不是“管理员”）；stdout 实时可见；点“停止”能正常结束；日志中不出现“无法以标准权限启动”之类错误。 | ☐ |
| 4 | 在场景 3 的进程运行期间，用任务管理器**结束 `gostGUI.exe` 进程**（不是正常退出）。 | 所有子进程随之消失：普通项、经中转的项、以及任何**提权**的中转/目标进程都不得残留（可在任务管理器搜索 `gostGUI.Runner.exe`、`cmd.exe`、测试程序名确认）。 | ☐ |
| 5 | 让一个勾选了“以管理员身份运行”的项处于运行状态，正常退出 gostGUI，再重新启动 gostGUI。 | 启动时**不弹任何 UAC**；该项自己的日志出现且仅出现一行 `已跳过：需要管理员权限，请手动启动`（无前缀）；该项保持“已启用”状态；点“全部启动”后才会逐项弹 UAC（每个管理员项一次）。 | ☐ |
| 6 | 主题三态切换：顶部主题按钮依次选“跟随系统 / 浅色 / 深色”，每次切换后关闭并重启 gostGUI。 | 界面立即按选择切换（浅/深配色、日志区、列表、菜单、滚动条一致，深色标题栏同步）；重启后仍保持上次选择；“跟随系统”时修改 Windows 应用主题，gostGUI 在不重启的情况下跟随变化。 | ☐ |
| 7 | 退出时保存配置失败：把 `config.json` 设为只读（或把配置目录设为不可写），修改任意设置后从托盘“退出”。 | 退出过程中弹出**模态框**，明确显示中文保存失败原因；不会静默丢配置、不会崩溃；关闭弹框后进程正常退出。 | ☐ |
| 8 | 窗口几何记忆：调整窗口大小/位置 → 最小化 → 还原 → 隐藏到托盘 → 从托盘恢复 → 托盘“退出” → 重启。 | 每一步的尺寸/位置都与上一步一致；最小化不会把保存尺寸改小；重启后恢复到退出前的大小/位置/最大化状态（跨不同缩放比例也不应逐次变大或变小）。 | ☐ |
| 9 | **125% / 150% / 200%** 缩放：在 Windows 显示设置分别切到 125%、150%、200%（必要时注销/重启），启动 gostGUI，检查 1024×640 DIP 的最小布局。 | 文字清晰不模糊、不重叠；所有按钮/输入框完整可见、无裁切；右侧设置区在高度不足时可纵向滚动；日志区占据剩余高度；左栏可折叠/展开且不遮住右栏。 | ☐ |
| 10 | **窄桌面防御**：把工作区临时改成明显窄于 1024×640 DIP（例如 800×600 或远程会话小屏），启动 gostGUI。 | 窗口被夹到工作区内（不越界、不跑出屏幕）；最小尺寸按工作区放宽而不是强行撑破屏幕；左栏自动/手动折叠后主要按钮仍可点到；不出现按钮被裁掉或无法操作的情况。 | ☐ |
| 11 | **托盘双击还原**（`SendInput` 取代 `keybd_event` 的路径）：把窗口最小化或被其他窗口完全遮挡，双击托盘图标。 | 窗口立即恢复并置于最前、获得键盘焦点（与本清单第 8 条的托盘恢复一致）；之后在其它程序里按 Alt 键行为正常（没有卡住的 Alt 状态）；连续双击 3 次结果一致。 | ☐ |
